# 🎧 MateSonidos

**MateSonidos** es una plataforma web gratuita de matemáticas accesibles, diseñada para favorecer el aprendizaje de estudiantes ciegos, con baja visión y otras necesidades de apoyo.

El proyecto utiliza voz, interacción mediante teclado y una interfaz simple para que los estudiantes puedan aprender de forma autónoma e inclusiva.

---

## 🎯 Objetivos

- Favorecer el aprendizaje de las matemáticas mediante actividades accesibles.
- Incorporar síntesis de voz para acompañar cada actividad.
- Garantizar el uso mediante teclado.
- Desarrollar recursos gratuitos y de código abierto.
- Promover el Diseño Universal para el Aprendizaje (DUA).

---

## ✨ Características

- 🔊 Lectura por voz mediante SpeechSynthesis.
- ⌨️ Compatible con teclado.
- 📱 Funciona directamente en el navegador.
- 🎨 Interfaz clara y de alto contraste.
- 📊 Registro de aciertos y errores.
- 🏆 Retroalimentación inmediata.

---
